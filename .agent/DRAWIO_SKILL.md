# Skill: Draw.io Diagram Generator (drawio-skill)

Esta skill permite generar diagramas arquitectónicos de nivel profesional para pipelines de datos, MLOps, microservicios y sistemas cuantitativos.

## 🎯 Capacidades
1. **Flujos MLOps & DataOps:** Visualizar la ingesta de datos, pre-procesamiento, selección de características, entrenamiento de modelos ML (LightGBM/PyTorch), métricas y salidas en tiempo real.
2. **Entradas & Salidas:** Demostrar exactamente las variables de entrada ($X$), las transformaciones ($f(X)$) y las variables de salida ($y, \text{v2\_verdict}, \text{risk\_metrics}$).
3. **Métricas de Confiabilidad:** Mostrar precisión fuera de muestra (OOS Win Rate), ROC-AUC, F0.5-Score y velocidad del ciclo.
